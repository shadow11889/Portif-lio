Plataforma web institucional e portfólio multidisciplinar da **Gomes Industries**. O ecossistema unifica soluções em Design Visual, Pós-produção Audiovisual e Engenharia de Software (Micro-SaaS).

---

## 🚀 Sobre o Projeto

O site foi desenvolvido do zero focado em performance, sem dependência de frameworks pesados, aplicando as melhores práticas de layout responsivo, arquitetura CSS modular e estética *Dark Mode Premium*.

### 🛠️ Tech Stack & Recursos
- **Estrutura:** HTML5 Semântico
- **Estilização:** CSS3 nativo utilizando Custom Properties (`:root`), Flexbox e Grid Layout
- **Tipografia:** Playfair Display (Serif) & Montserrat (Sans-serif)
- **UI/UX:** Design responsivo adaptado para mobile e desktop com rolagem suave nativa
